## NUF-036 remains open: an actual modifier list cannot select a pre-roll policy

The current armor reader accepts an empty/fixed-assist actual modifier list without independently ruling out an eligible post-roll modifier. It excludes a used Mighty Blow armor bonus. A controlled AV8 scaffold with the same complete opposing Mighty Blow13 traits before every draw demonstrates the problem.

The [stdlib reference](../scripts/reference-armor-choice-policy.py) derives all72 ordered face cases for two fixed decision policies. Never using the bonus leaves21/36 armor holds. Using it exactly on an unmodified7 leaves15/36 holds. Each complete correct policy has exact zero expected dice deviation. GR-005 and the hash-bound BB2020 printed80/PDF81 rule evidence in [the armor-budget record](ARMOR_MODIFIER_BUDGET_EVIDENCE.md) establish that this choice can follow the armor dice; a prior emitted usage notification is not automatically a pre-roll commitment.

The [runnable reproduction](../scripts/probe-armor-choice-policy.ts) uses the same pre-roll scaffold for every face, changes dice/observed outcome, and omits the injury when armor holds. Under never-use, all36 armor records are scored with mean approximately zero. Under use-on-seven, six modified records are excluded while the other30 are scored with mean−1/12 among admitted records. Excluded records are **unknown**, not zero; this is an admission/benchmark counterexample, not an estimate that their true contribution is zero or a whole-policy luck mean.

Run `python3 scripts/reference-armor-choice-policy.py --check`, then `node --import tsx scripts/probe-armor-choice-policy.ts`. The latter intentionally reports the open defect with exit1. It is a reproduction, not a passing acceptance gate or skipped unit test. The first attempted tsx CLI invocation was blocked by its local IPC socket; the Node import-loader invocation runs without that socket and produces the actual result.

NUF-036 must establish the relevant policy before observing the die, or use a separately defined outcome-independent draw metric with a complete fair-face proof. It must retain positive, independently annotated ordinary/fixed-modifier cases and keep unsupported dice/roles visible. Empty actual modifiers or a post-roll use notice alone are insufficient. Every changed public admission/value/derived total needs independent source/whole-report reconciliation; existing hashes must not be silently reset. The reference should become a passing automated regression with that correction. Broader context/calibration and original acceptance requirements remain intact.
